## Автоматический локальный просмотр — 25 ноября
Для постоянного просмотра настроена пользовательская задача Windows «Linqueenn Portfolio Preview»: скрытый запуск при входе пользователя, без повышения прав, без ограничения времени и с восстановлением после ошибки. Она запускает scripts/preview-keepalive.cjs, который обслуживает http://127.0.0.1:4176/portfolio/ через прежний preview-pages.cjs и восстанавливает сервер через 2.5 секунды после его завершения. При отсутствии dist запускается prepare-pages. Node находится через PATH или актуальный пакет OpenAI.CodexPrimaryRuntime; путь конкретной версии не зафиксирован. Состояние PID хранится только в игнорируемой .portrait-processing/preview-state.json.
Причина прежних ежедневных ошибок: временный сервер из окружения Codex завершался; на момент обращения порт4176 не прослушивался. Больше не запускать постоянный preview через Start-Process из Codex. При необходимости использовать Start-ScheduledTask -TaskName 'Linqueenn Portfolio Preview'. Временный дублирующий VBS из Startup удалён. Проверено: задача Running, страница Vinyl отдаёт HTTP200; после проверенного завершения дочернего процесса сервер автоматически восстановился и снова отдаёт HTTP200. Реальная перезагрузка Windows не выполнялась. Публичная публикация и дизайн не менялись.
