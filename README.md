# Портфолио Лины

Статический сайт: HTML, CSS, JavaScript и локальная копия Three.js. Установка npm-пакетов не требуется. Дизайн и анимации при подготовке публикации не преобразуются.

## Проверка GitHub Pages локально

```sh
node scripts/prepare-pages.cjs
node scripts/preview-pages.cjs
```

Открыть http://127.0.0.1:4175/portfolio/ — это копия файлов для публикации, размещённая под тем же префиксом, что и репозиторий `portfolio`. Проверить также `?lang=en`, `?case=roma` и ссылки меню. Сервер только для локальной проверки.

## Резюме

Сборка публикует две предоставленные версии: `assets/Lina_Khannanova_CV_RU.pdf` и `assets/Lina_Khannanova_CV_EN.pdf`. Сайт выбирает PDF по языку страницы. Надпись CV открывает PDF, кнопка со стрелкой скачивает его.

Локальный `assets/cv.pdf` исключён из Git и сборки.

## Публикация

1. Создать на GitHub репозиторий `portfolio`, добавить текущий код и рабочие ресурсы. Приватное резюме, исходные MOV/MP4, временные обработки и `dist/` исключены через `.gitignore`. Не использовать принудительное добавление игнорируемых файлов.
2. Проверить обе языковые версии резюме в локальной сборке.
3. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**.
4. Отправить изменения в `main` или `master` либо вручную запустить workflow **Publish portfolio to GitHub Pages**.
5. Публичный адрес: `https://<имя-пользователя>.github.io/portfolio/`.

Workflow `.github/workflows/pages.yml` формирует `dist/` по явному списку публичных файлов и публикует только эту папку. В неё не попадают `AGENTS.md`, `PROJECT_NOTES.md`, локальные серверы, инструменты обработки, оригинальные видео и остальные файлы проекта. Исходные файлы локально не удаляются. Неиспользуемые старые экспорты исключены из текущего Git-индекса; предыдущие локальные коммиты не переписывались.

Относительные пути поддерживают `/portfolio/` без `<base>`, изменения роутинга и сборщика. Страницы кейсов используют параметры запроса, поэтому отдельные HTML-файлы и SPA-редиректы не нужны. Внешние Google Fonts, Telegram, WhatsApp и соцсети требуют доступа к соответствующим сервисам.

Настройка workflow соответствует [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
