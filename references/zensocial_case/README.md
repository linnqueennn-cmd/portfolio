# ZenSocial — HTML-кейс для портфолио

## Открыть
Откройте `index.html` в браузере. Интернет не нужен для изображений и верстки. Кнопки App Store ведут на действующую страницу приложения.

## Редактировать
- `index.html` — весь текст, структура, подписи, плейсхолдеры.
- `styles.css` — композиция, адаптив, цвета, оформление персоны и CJM.
- `script.js` — сравнение экранов и просмотр изображений.
- `assets/` — оригинальные изображения и скриншоты.

## Материалы и статусы
- `cover_before_after.webp`, `source_filters.webp`, `source_appearance.webp`, `source_time.webp`, `source_summary.webp` — оригинальные файлы пользователя.
- `before_01.webp`…`before_15.webp` — исходные 15 экранов, вырезанные из предоставленного `app.pdf`.
- `after_01.webp`…`after_05.webp` — окончательная согласованная последовательность 5 экранов, вырезанная из последнего скриншота пользователя (`image(20261123-183000).png`). Исходник — обзор пяти фреймов, поэтому эти миниатюры не в высоком разрешении. Для финальной публикации лучше заменить экспортами соответствующих кадров из Figma (390×844, 2x/3x).
- `auth_login.webp`, `auth_settings.webp` — исходные экраны из PDF.
- Два светлых телефона-заглушки в конце — **не настоящие скриншоты**, их нужно заменить после получения материалов из рабочего приложения.
- Персона, CJM и гипотезы — аналитические модели, а не данные проведённых интервью.
- Переработка онбординга из 15 в 5 экранов — дизайн-предложение, не подтверждённое внедрение или рост конверсии.

## Перед публикацией
1. Заменить два плейсхолдера реальными экранами после входа в Instagram.
2. Вставить отдельные экспортированные изображения пяти финальных экранов онбординга.
3. Проверить уточнённую роль/команду, метрики (если есть), год и статус внедрения.
4. Сверить оттенки и название шрифтов с файлами проекта (точный шрифт исходников пока не подтверждён).
5. При встраивании на существующий сайт синхронизировать внешнюю оболочку с его шрифтами и сеткой.
